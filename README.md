# ft_transcendence

A web application developed as part of the 42 curriculum.

## Overview

The goal of this project is to build a web application with a frontend, backend, and database, following a collaborative development workflow.

## Tech Stack

- **Frontend:** Vue.js
- **Backend:** NestJS (Node.js)
- **Database:** PostgreSQL
- **ORM:** TypeORM
- **Communication**: WebSockets
- **API Documentation**: Swagger
- **Reverse Proxy:** Nginx
- **Containerization:** Docker and Docker Compose
- **CI:** GitHub Actions

*The final technology choices will be agreed upon by the team.*
